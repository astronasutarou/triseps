# trired &ndash; apply basic calibration

Reduce one TriCCS FITS image or image cube using a database generated by
[tripre](tripre.md). Optionally solve its WCS, align frames with a target
ephemeris, and combine the cube into a 2D image.

## Usage

``` text
trired [-w] [-q | -s] [--track FILE] [-r] [-f] [-v]
       [GAIA_OPTIONS] DATABASE FITS OUTPUT
```

### Arguments

| Argument | Description |
| --- | --- |
| `DATABASE` | Calibration database FITS file produced by `tripre`. |
| `FITS` | Input observation FITS file. Only the Primary HDU is processed. |
| `OUTPUT` | Destination FITS file. |

The input `FRAMEID` must already be registered in the database, and matching
dark and flat extensions must exist. Dark selection uses detector,
single-exposure time, gain, and effective area. Flat selection uses detector,
filter, and effective area. There is no fallback to a nearby exposure time or
to a different filter, and dark images are not rescaled for exposure time.

### Options

| Option | Description |
| --- | --- |
| `-w`, `--wcs` | Solve the spatial WCS with Gaia DR3 after basic calibration and before any alignment or stacking. See [triwcs](triwcs.md) for prerequisites. |
| `-q`, `--ql` | Produce a 2D quick-look image by taking the ordinary arithmetic mean along the time axis. Requires a 3D input; does not reject outliers or ignore NaNs. |
| `-s`, `--stack` | Produce a 2D image using a 3-sigma-clipped mean along the time axis, excluding nonfinite samples. Requires a 3D input. |
| `--track FILE` | Align a 3D cube on a moving target, assuming it was observed with sidereal tracking. Read positions from a Seimei `_tk.dat` ephemeris. |
| `-r`, `--reverse` | Reverse the ephemeris shifts: assume the telescope tracked the target and align the cube on background stars. Requires `--track`. |
| `-f`, `--overwrite` | Replace an existing output file. |
| `-v`, `--verbose` | Show reference/detection/inlier counts and fit RMS with `--wcs`. Basic processing messages are printed regardless of this flag. |
| `-h`, `--help` | Show help and exit. |

`--ql` and `--stack` are mutually exclusive. `--track` cannot be combined
with `--ql`; use `--stack` to combine aligned frames. `--reverse` without
`--track` is an error. With neither `--ql` nor `--stack`, the input number
of dimensions is retained.

### Gaia solver options

These settings take effect with `--wcs`; they do not enable WCS solving by
themselves. See [triwcs](triwcs.md) for matching, timing, and catalog details.

| Option | Description |
| --- | --- |
| `--wcs-image {first,mean}` | Detect on the first cube frame (default) or a clipped mean. This selection does not control output stacking. |
| `--wcs-sip-degree {0,2,3}` | Forward SIP degree; default `3`. CD is fixed and CRPIX is fixed at the cropped image center. `0` fits only CRVAL. |
| `--gaia-catalog FILE` | Use a local Gaia table instead of an online query. |
| `--gaia-mag-limit MAG` | Gaia G faint limit; default `18`. |
| `--wcs-fwhm PIXELS` | Expected detection FWHM; default `3` pixels. |
| `--wcs-threshold SIGMA` | Detection threshold; default `5` background sigma. |
| `--wcs-match-radius PIXELS` | Matching tolerance after correcting the pointing offset; default `3` pixels. |
| `--wcs-max-rms PIXELS` | Maximum accepted fit RMS; default `1` pixel. |

The approximate plate scale and orientation in the header must be correct.
Gaia proper motions are propagated to the detection image's observation epoch.
The default fit updates CRVAL and quadratic/cubic SIP coefficients, keeping
CD fixed and CRPIX at the cropped image center. It requires at least 12 inliers.
Use first-frame detection for non-sidereal observations. A mean before
tracking does not align stars, and may smear their images.

## Processing

1. Extract the effective photo-sensitive area and convert the data to floating
   point. Adjust spatial `CRPIX` values for the crop.
2. Subtract the matching dark image from every exposure.
3. Divide every exposure by the matching flat image. Zero or nonfinite flat
   pixels produce `NaN` in the output.
4. If requested, solve the WCS using Gaia DR3. For a cube, detection
   uses its first frame by default, or a mean with `--wcs-image mean`.
5. If `--track` is supplied, shift each frame relative to the first frame.
6. If requested, combine the frames into a 2D image.

Reference-pixel bias estimation, source photometry, and photometric zeropoint
calibration are not performed.

## Tracking and alignment

| Options | Assumed observation tracking | Output alignment | Output shape |
| --- | --- | --- | --- |
| `--track FILE` | Sidereal | Moving target | 3D cube |
| `--track FILE -r` | Target ephemeris | Sidereal | 3D cube |
| `--track FILE -s` | Sidereal | Moving target | 2D image |
| `--track FILE -r -s` | Target ephemeris | Sidereal | 2D image |

Without `--track`, frames are not shifted. In particular, `--stack` alone
does not detect stars or register images before averaging.

### Ephemeris and timing requirements

The supported file is the Seimei [`_tk.dat` format](../inst/nonsidereal.md#format).
The first line is skipped as a target/range description. Subsequent CSV rows
provide UTC JD in the second field, RA in the fifth field, and Dec in the sixth
field. RA uses hours/minutes/seconds and Dec uses signed degrees/minutes/seconds.
Coordinates are interpreted as ICRS. At least two finite, strictly increasing
timestamps and finite positions are required.

For frame index `i`, starting at zero, the exposure midpoint is:

``` text
GEXP-STR + i * TFRAME + EXPTIME1 / 2
```

`GEXP-STR` must identify the first exposure start; `TFRAME` and `EXPTIME1`
are positive finite values in seconds. `TIMESYS` gives the time scale and
defaults to UTC. Exposures are assumed equally spaced, without dropped frames.
All midpoints must lie within the ephemeris range; extrapolation is rejected.

Positions are interpolated linearly as Cartesian unit vectors and then
normalized, so crossing RA zero is supported. A celestial WCS is required to
project them into the reference frame's pixel coordinates. An existing WCS
can be used without `--wcs`.

### Shift convention and interpolation

Let `p[i]` be the target position at midpoint `i`, projected using the first
frame's spatial WCS. The applied translation is:

``` text
--track FILE:       -(p[i] - p[0])
--track FILE -r:     +(p[i] - p[0])
```

The first frame has zero translation. Bilinear interpolation retains the
cropped input width and height. A destination pixel becomes `NaN` if any
contributor with nonzero interpolation weight is outside the image or
nonfinite. There is no wrapping or zero padding.

This is a translation-only model with fixed scale and orientation. It does
not measure tracking errors, correct field rotation, or remove motion within
an exposure. Reverse alignment assumes the telescope followed the supplied
target ephemeris.

## Output

The Primary HDU contains the calibrated image, shifted cube, or combined image.
Input extensions are not copied. With `--track`, a `SHIFTS` binary table is
added; no second image aligned in the other reference system is generated.

Stacked values are means in the calibrated input units, not summed counts or
count rates. The original exposure metadata are retained: in particular,
`EXPTIME` is not adjusted to describe the normalization of a mean image.
Do not divide the mean by the original total exposure time to obtain a count
rate. Pixels without valid samples remain `NaN` in a clipped-mean stack.

When producing a 2D image, third-axis WCS keywords are removed and `WCSAXES`
is set to 2. Processing steps and timing are recorded in `HISTORY`.

### Tracking metadata

| Primary header keyword | Meaning |
| --- | --- |
| `TRKALIGN` | `TARGET` for ordinary tracking alignment, or `SIDEREAL` for reverse alignment. |
| `TRKINTER` | `BILINEAR`. |
| `TRKREF` | Zero-based reference frame index, always `0`. |
| `TRKMJD` | First exposure midpoint as UTC MJD. |

The spatial WCS refers to the first exposure. For target-aligned output, it
is a reference-time mapping, not the absolute sky mapping of every shifted
frame. The ephemeris filename is recorded in `HISTORY`.

| `SHIFTS` column | Meaning |
| --- | --- |
| `frame` | Zero-based input frame index. |
| `mjd_utc` | Exposure midpoint, UTC MJD in days. |
| `dx` | Applied translation in pixels; positive moves content toward increasing column index. |
| `dy` | Applied translation in pixels; positive moves content toward increasing row index. |

## Examples

Basic reduction, preserving the cube:

``` console
$ trired database.fits science.fits reduced.fits
```

Calibrate the WCS and make a clipped-mean image without alignment:

``` console
$ trired database.fits science.fits stacked.fits --wcs --stack
```

Align sidereal observations on a target, preserving individual exposures:

``` console
$ trired database.fits science.fits target_cube.fits --track target_tk.dat
```

Align target-tracked observations on stars and combine them:

``` console
$ trired database.fits science.fits stars.fits --track target_tk.dat -r -s
```

See also the [reduction tutorial](../tutorial/reduction.md).
